# MoviesRecommender v1.0

MoviesRecommender - учебный проект, реализованный на языке Java с графическом интерфейсом (Swing), которое рекомендует фильмы на основе твоих предпочтений и вкусов друзей.

# Функционал
- регистрация и вход пользователей
- оценка фильмов (лайк, просмотр, дизлайк)
- добавление/удаление друзей и учет их вкусов
- фильтрация/поиск на каждой вкладке
- просмотр профиля друзей
- персональные рекомендации на основе ML (Apache Mahout)

# Стек технологий
- Язык: Java
- Интерфейс: Swing
- База данных: PostgreSQL
- Машинное обучение: Apache Mahout
- Сборка: Maven
- Работа с БД: JDBC

# Алгоритм обучения
- Глобальная модель: обучается на всех пользователях и переобучается каждые 50 пользовательских итераций
- Персональные модели: создаются на основе глобальной и дообучаются на действиях конкретного пользователя
- Социальные корреляции: рассчитываются через коэффициенты Жаккара и Пирсона, влияя на итоговые рекоммендации (ищет похожих по предпочтениям пользователей)
- Финальный фактор: учитывает модель, жанры, рейтинг, год, популярность у друзей

# Установка и запуск
Требования: Java 17+, PostgreSQL, Maven

# Настройка БД:
1. Добавить БД movies_final
2. В файле 'src/main/resources' создать файл config.properties и указать:
- db.url=jdbc:postgresql://localhost:5432/movies_final
- db.user=postgres
- db.password=твой_пароль
3. Создать таблицы friends, liked, disliked, users, watched

# Рекомендации по улучшению
1. Необходимо доработать веса рекомендательной системы, для более чётких рекомендаций (пока сыро).
2. Есть незначительные баги со скроллом (обновляется при каждой пользовательской итерации).
3. Есть баги с переключением страниц во вкладке рекомендаций (долго думает).
4. Данные во вкладке с аналитикой обновляются при каждом заходе (должны обновляться сразу при какой-либо итерации)
5. Пользовательские данные (пароль/логин должны хэшироваться в идеале)
